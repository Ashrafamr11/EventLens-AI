
# EventLens AI

## Project Overview

EventLens AI is a deep learning-based system for
Audio-Visual Event Detection and Temporal Localization.

The system analyzes both video and audio to identify
events and determine their start and end timestamps.

## Main Features

- Upload and analyze videos.
- Detect audio-visual events.
- Identify event start and end times.
- Display all detected events.
- Jump directly to events in the video.

## Deep Learning Requirements

- A baseline model.
- Three deep learning approaches:
  - Classic architecture
  - Modern architecture
  - Advanced architecture
- Model training and evaluation.
- Fair model comparison.
- Hyperparameter and data strategy studies.
- Ablation study and error analysis.
